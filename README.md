## 写作说明

- 文件名用 `数字-标题.md` 格式，放进对应分类目录即可，导航和列表会自动更新。
- 需要置顶或打标签时，在文章开头加 frontmatter：

```yaml
---
pin: true
tags: [基础, Java]
---
```

`pin: true` 让文章排在同级最前；标签会显示在列表页的筛选栏。文章页会自动显示阅读时长、更新日期和目录。
